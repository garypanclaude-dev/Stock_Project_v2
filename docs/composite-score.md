# 綜合投資評分系統 (Composite Investment Score)

> 版本：2.0
> 最後更新：2026-06-10
> v2.0：B7 整合 — 技術面 4 → 6 子指標，新增 KD、OBV；均線排列升級為 4 態分類（含糾結判定）

## 概述

將技術面、基本面、新聞情緒三大維度整合成 **0-100 分**的綜合投資評分，搭配 AI 生成的文字研判，幫助投資人快速判斷個股的綜合狀態。

**設計原則**：分數由規則引擎計算（快速、穩定、可重現），文字研判由 Gemini AI 生成（有深度、但失敗不影響分數）。

---

## 評分架構

```
綜合評分 = 技術面 × 40% + 基本面 × 35% + 情緒面 × 25%
```

> 當情緒面不可用時（AI 失敗），自動重新分配：技術面 55% + 基本面 45%

### 評分等級對照

| 分數區間 | 等級 | 顏色 | 說明 |
|---------|------|------|------|
| 81-100 | 強勢 (Strong) | 深綠 `#16a34a` | 多數指標偏多，適合積極佈局 |
| 61-80 | 偏多 (Bullish) | 綠色 `#22c55e` | 整體偏正面，可考慮進場 |
| 41-60 | 中性 (Neutral) | 黃色 `#f59e0b` | 多空訊號交織，建議觀望 |
| 21-40 | 偏空 (Bearish) | 紅色 `#ef4444` | 多數指標偏空，謹慎操作 |
| 0-20 | 弱勢 (Weak) | 深紅 `#dc2626` | 明顯弱勢，建議避開或減碼 |

## 子維度 1：技術面分數 (Technical Score)

**權重：40%**

以下 **6 個子指標** 各自計算 0-100 分後，依權重加總為技術面總分。

### 子指標權重總覽（v2.0）

| 子指標 | 權重 | 性質 |
|--------|------|------|
| RSI(14) | 15% | 動能震盪 |
| MACD(12,26,9) | 15% | 趨勢動能 |
| 均線排列 | 20% | 多頭/空頭/糾結 四態 |
| 布林通道位置 | 15% | 統計區間 |
| KD(9,3,3) | 20% | 動能交叉 |
| OBV | 15% | 量價配合 |

> v2.0 變動：原 4 指標權重 25/25/30/20 → 6 指標權重 15/15/20/15/20/15

### 1.1 RSI 分數（權重 15%）

| RSI 值 | 分數 | 邏輯 |
|--------|------|------|
| < 20 | 85 | 極度超賣，反彈機率高 |
| 20-30 | 75 | 超賣區，逢低佈局 |
| 30-45 | 60 | 偏弱但未超賣 |
| 45-55 | 50 | 中性 |
| 55-70 | 65 | 偏多，趨勢健康 |
| 70-80 | 40 | 超買區，追高風險 |
| > 80 | 25 | 極度超買，回調風險高 |
| 無資料 | 50 | 預設中性 |

> **設計理由**：RSI 並非越高越好。超買（>70）意味著短期追高風險增加，超賣（<30）則可能是反彈機會。

### 1.2 MACD 分數（權重 15%）

| 條件 | 分數 |
|------|------|
| MACD > Signal 且 Histogram 擴大（多頭增強） | 80 |
| MACD > Signal 且 Histogram 縮小（多頭減弱） | 65 |
| MACD < Signal 且 Histogram 縮小（空頭減弱） | 45 |
| MACD < Signal 且 Histogram 擴大（空頭增強） | 20 |
| 資料不足 | 50 |

### 1.3 均線排列分數（權重 20%，v2.0 升級為 4 態分類）

不再用累加加分，改為**互斥四態判定**：

| 狀態 | 判定條件 | 分數 | 顏色 |
|------|---------|------|------|
| 多頭排列 | MA5 > MA10 > MA20 > MA60 且 收盤 > MA5 | 90 | 🟢 |
| 空頭排列 | MA5 < MA10 < MA20 < MA60 且 收盤 < MA5 | 15 | 🔴 |
| 均線糾結 | (max - min) / mean < 3% | 50 | 🟡 |
| 均線交錯 | 以上都不符合（中性） | 50 | ⚪ |

**判定優先級**：糾結 > 多頭 > 空頭 > 中性。糾結優先是因為「四條均線貼近」代表變數較大，需要等突破方向確認。

> **為什麼糾結也是 50 分？** 糾結本身不是看多也不是看空，是「等變盤」訊號。給中性 50 分讓使用者不會因糾結而被誤導買進或賣出。

### 1.4 布林通道位置分數（權重 15%）

以收盤價在通道中的位置計算（0% = 下軌，100% = 上軌）：

| 通道位置 | 分數 | 邏輯 |
|---------|------|------|
| < 10% | 70 | 貼近下軌，超賣反彈 |
| 10-30% | 55 | 偏低，觀望 |
| 30-70% | 65 | 通道中段，趨勢健康 |
| 70-90% | 50 | 偏高，注意壓力 |
| > 90% | 30 | 貼近上軌，超買風險 |
| 無資料 | 50 | 預設 |

### 1.5 KD 分數（權重 20%，v2.0 新增）

**台股版 KD 公式**（9-3-3 平滑）：

```
RSV_t = (close_t - low_9d) / (high_9d - low_9d) × 100
K_t   = 2/3 × K_{t-1} + 1/3 × RSV_t
D_t   = 2/3 × D_{t-1} + 1/3 × K_t
```

**基礎分數（依 K 值區間查表）**：

| K 值 | 分數 | 邏輯 |
|------|------|------|
| < 20 | 85 | 嚴重超賣，反彈機率高 |
| 20-30 | 75 | 超賣 |
| 30-50 | 60 | 偏弱但未超賣 |
| 50-70 | 50 | 中性 |
| 70-80 | 35 | 偏強但接近超買 |
| > 80 | 20 | 嚴重超買，回調風險 |
| 無資料 | 50 | 預設 |

**交叉修正項**：

| 條件 | 修正 |
|------|------|
| 黃金交叉於低檔（K 由下穿越 D，且 K < 50） | **+10** |
| 死亡交叉於高檔（K 由上穿越 D，且 K > 50） | **-10** |

最終 KD 分數會 clamp 到 0-100。

### 1.6 OBV 分數（權重 15%，v2.0 新增）

**On-Balance Volume 計算**：

```
OBV_0 = 0
OBV_i = OBV_{i-1} + volume_i   if close_i > close_{i-1}
      = OBV_{i-1} - volume_i   if close_i < close_{i-1}
      = OBV_{i-1}              if close_i == close_{i-1}
```

**評分依據**：比對「5 日 OBV 斜率」vs「5 日股價斜率」的方向組合：

| 情境 | 條件 | 分數 | 解讀 |
|------|------|------|------|
| 量價齊揚 | 價 ↑ + OBV ↑ | 75 | 健康上漲，資金進場 |
| 看多背離 | 價 ↓ + OBV ↑ | 70 | 跌而量增 = 籌碼吸納 |
| 中性 | 其中一邊持平 | 50 | 訊號不明確 |
| 看空背離 | 價 ↑ + OBV ↓ | 30 | 漲而量縮 = 動能轉弱 |
| 量價齊跌 | 價 ↓ + OBV ↓ | 25 | 弱勢下跌，資金撤出 |
| 無資料 | 樣本不足 | 50 | 預設 |

> **看空背離（30 分）為什麼比量價齊跌（25 分）還低？** 因為背離意味著「價格在說謊」—— 上漲表象掩蓋了資金已悄悄出走，常是大波段下跌的前兆。直觀的弱勢下跌反而是大家都看到的訊息。

## 子維度 2：基本面分數 (Fundamental Score)

**權重：35%**

### 2.1 本益比 P/E 分數（權重 25%）

| P/E 值 | 分數 | 邏輯 |
|--------|------|------|
| < 0 或 None | 30 | 虧損或無資料 |
| 0-10 | 85 | 極低估 |
| 10-15 | 75 | 低估 |
| 15-25 | 65 | 合理 |
| 25-35 | 50 | 略高 |
| 35-50 | 35 | 偏高 |
| > 50 | 20 | 高估 |

> **注意**：不同產業的 P/E 基準差異很大，此為通用標準。未來可加入產業 P/E 均值比較。

### 2.2 ROE 分數（權重 20%）

| ROE 值 | 分數 | 邏輯 |
|--------|------|------|
| < 0 | 10 | 虧損 |
| 0-5% | 25 | 獲利能力弱 |
| 5-10% | 45 | 普通 |
| 10-15% | 60 | 良好 |
| 15-25% | 75 | 優秀 |
| > 25% | 90 | 極優 |
| 無資料 | 50 | 預設 |

### 2.3 營收成長趨勢分數（權重 25%）

根據最近 4 季的季營收 QoQ（季對季）變化判斷趨勢：

| 趨勢 | 分數 | 判斷方式 |
|------|------|---------|
| 連續 3 季成長 | 90 | Q1 < Q2 < Q3 < Q4 |
| 連續 2 季成長 | 75 | 最近 2 季遞增 |
| 成長 1 季 | 60 | 最近 1 季成長 |
| 持平 | 50 | 變化率 < 5% |
| 衰退 1 季 | 40 | 最近 1 季衰退 |
| 連續衰退 | 20 | 連續 2+ 季衰退 |
| 無資料 | 50 | 預設 |

### 2.4 Profit Margin 分數（權重 15%）

| Profit Margin | 分數 |
|---------------|------|
| < 0 | 10 |
| 0-5% | 30 |
| 5-10% | 45 |
| 10-20% | 65 |
| 20-30% | 80 |
| > 30% | 90 |
| 無資料 | 50 |

### 2.5 股利分數（權重 15%）

| 條件 | 分數 |
|------|------|
| Yield > 4% | 85 |
| Yield 2-4% | 70 |
| Yield 0.5-2% | 55 |
| Yield < 0.5% 或無配息 | 40 |
| 無資料 | 50 |

> **設計理由**：股利為加分項。無配息不代表差（如成長股），但有穩定配息是額外優勢。

## 子維度 3：情緒面分數 (Sentiment Score)

**權重：25%**（AI 不可用時權重歸零）

### 3.1 多空比例分數（權重 60%）

```
分數 = (bullish / total) × 100
```

若 total = 0，分數 = 50（中性）。

### 3.2 催化劑數量分數（權重 20%）

| 催化劑數量 | 分數 |
|-----------|------|
| 0 | 50 |
| 1-2 | 60 |
| 3-5 | 70 |
| > 5 | 65（太多可能代表市場雜訊多） |

### 3.3 催化劑類型權重分數（權重 20%）

依催化劑類型的市場影響力加權：

| 類型 | 影響力權重 |
|------|----------|
| earnings | 1.0（最高） |
| regulation | 0.9 |
| m_and_a | 0.85 |
| analyst_rating | 0.8 |
| management | 0.7 |
| litigation | 0.7 |
| product_launch | 0.6 |
| macro | 0.5 |

計算方式：以 bullish 催化劑的加權影響力 vs bearish 催化劑的加權影響力，算出 0-100 分。

## AI 文字研判

### Prompt 設計

在現有的新聞分析之外，另外呼叫 Gemini（或合併到同一次呼叫）生成研判文字：

**輸入**：綜合評分結果 + 關鍵指標數據
**輸出**：100 字以內繁體中文研判

### 輸出格式範例

```
技術面多頭排列，RSI 65 尚未超買；基本面 PE 33 略高於產業均值但 ROE 157% 極強；
近期 2 則利多催化劑（財報超預期 + 分析師上調目標價）。
短期策略建議：可逢回佈局，支撐位 $295，壓力位 $320。
```

### Graceful Degradation

- AI 研判失敗時，顯示「AI 研判暫時不可用」
- 分數仍正常顯示（規則引擎計算，不依賴 AI）

## 前端呈現

### 評分儀表板卡片

位置：Dashboard 最上方，與價格卡並排。

包含元素：
1. **圓環圖**：顯示 0-100 分 + 等級文字，顏色依等級對照表
2. **三個子維度進度條**：技術面 / 基本面 / 情緒面，各自的分數與進度條
3. **AI 研判文字區**：Gemini 生成的研判文字
4. **免責聲明**：底部固定顯示灰色小字

## 設定檔管理

所有閾值與權重應抽離到設定檔（`scoring_config`），避免 hard-code：

```python
SCORE_CONFIG = {
    "weights": {
        "technical": 0.40,
        "fundamental": 0.35,
        "sentiment": 0.25,
    },
    "fallback_weights": {  # 情緒面不可用時
        "technical": 0.55,
        "fundamental": 0.45,
    },
    "rsi_thresholds": [20, 30, 45, 55, 70, 80],
    "pe_thresholds": [0, 10, 15, 25, 35, 50],
    # ... 其餘閾值
}
```
